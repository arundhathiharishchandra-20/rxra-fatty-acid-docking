# In Silico Investigation of Fatty Acid Interactions with RXRα

## Overview

This repository contains my MSc research project on molecular docking of fatty acids with Retinoid X Receptor Alpha (RXRα).

The objective was to investigate the binding interactions of several saturated, monounsaturated, and polyunsaturated fatty acids with the RXRα ligand-binding domain using molecular docking.

## Fatty acids studied

- Docosahexaenoic acid (DHA)
- Eicosapentaenoic acid (EPA)
- Alpha-linolenic acid (ALA)
- Arachidonic acid
- Linoleic acid
- Oleic acid
- Palmitic acid

## Software

- Swiss-Model
- PyRx
- AutoDock
- UCSF ChimeraX
